❓ FAQ

Questions fréquentes

Tout ce que vous devez savoir avant de démarrer.

Comment fonctionne VidSpark AI ?
VidSpark AI est une extension Chrome qui s'intègre directement dans YouTube. Quand vous ouvrez une vidéo, elle analyse automatiquement le titre et la description pour calculer des scores SEO, Viral et Miniature. Pour les fonctionnalités IA (titres, description, tags), elle envoie ces données à notre backend sécurisé qui interroge le modèle Claude d'Anthropic. Aucune clé API n'est stockée dans votre navigateur.
Quelles vidéos YouTube puis-je analyser ?
Vous pouvez analyser n'importe quelle vidéo YouTube — la vôtre ou celle d'un concurrent. Le panel VidSpark AI apparaît automatiquement sur toutes les pages de vidéos YouTube (/watch) et YouTube Shorts (/shorts). C'est utile pour analyser les meilleures pratiques de votre niche.
Quelle est la différence entre le plan Free et Pro ?
Le plan Free donne accès à 5 analyses par jour avec les scores SEO, Viral et Miniature, ainsi que la checklist SEO. Le plan Pro supprime la limite d'analyses, ajoute le Rapport IA complet, la génération de titres (5 variantes), la description IA optimisée, les tags et hashtags IA, et l'historique de toutes vos analyses.
L'IA utilisée est-elle fiable ? Quelles données envoie-t-on ?
Nous utilisons Claude Sonnet d'Anthropic, l'un des modèles d'IA les plus performants du marché. Seuls le titre et la description de la vidéo sont transmis pour analyse. Ces données ne sont pas utilisées pour entraîner des modèles d'IA (politique API d'Anthropic). Aucune donnée personnelle ou de navigation n'est transmise à l'IA. Consultez notre politique de confidentialité pour tous les détails.
Puis-je résilier mon abonnement à tout moment ?
Oui, sans condition ni frais. Vous pouvez résilier depuis votre espace de facturation directement dans l'extension. La résiliation prend effet à la fin de la période en cours — vous conservez l'accès Pro jusqu'à cette date. Conformément à la réglementation européenne, un droit de rétractation de 14 jours s'applique sur le premier abonnement.
L'extension fonctionne-t-elle sur Microsoft Edge ?
Oui. VidSpark AI est compatible avec tous les navigateurs basés sur Chromium : Chrome, Edge, Brave, Vivaldi, Arc et Opera. Pour Edge, vous pouvez installer les extensions Chrome depuis le Chrome Web Store directement.
En quelles langues est disponible VidSpark AI ?
L'interface est disponible en 14 langues : Français, English, Español, Deutsch, Português, Italiano, Nederlands, Русский, 日本語, 한국어, 中文, العربية, हिन्दी et Türkçe. L'extension détecte automatiquement la langue de la vidéo analysée pour adapter les suggestions.
Mes données YouTube sont-elles sécurisées ?
VidSpark AI ne stocke que le titre et la description des vidéos que vous choisissez d'analyser (pour votre historique Pro). Votre historique de navigation YouTube, vos abonnements, vos commentaires ou vos données de chaîne ne sont jamais accessibles ni transmis. L'extension utilise uniquement les permissions strictement nécessaires. Consultez notre politique de confidentialité pour le détail de chaque permission.
